# ТЗ: оверлей PocketClipboard (двойной Alt) — читаемая переписка

Дата: 2026-10-24. Исполнитель — Hoplite. Сборку exe и проверку на Windows делает владелец (`bash tools/scripts/make-usb.sh` → `dist/usb/PocketClipboard.exe`).

## 1. Что есть

- Окно — `apps/clipboard-agent/src/overlay/script.ts`: PowerShell 5.1 + WinForms, один `RichTextBox`, 400×500 в правом нижнем углу, тёмная/светлая тема. Двойной Alt показывает, одиночный Alt / Esc прячет. Не забирает фокус.
- Данные — `apps/clipboard-agent/src/overlay/model.ts`: `OverlayModel` следит за чатом, который открыт на телефоне, и шлёт окну JSON-операции (`reset`, `upsert`, `title`, `status`, `theme`). `toMessage` превращает элементы чата (`user`, `assistant`, `tool`, `error`) в `OverlayMessage`.
- Процесс окна и перезапуск — `overlay/window.ts`. Тесты — `apps/clipboard-agent/test/overlay-*.test.ts`.

## 2. Проблема (со слов владельца)

Всё идёт одной сплошной колонкой: «You» серым мелким, «Claude» синим мелким, действия Claude — серая строка `⚙ Bash …`. Непонятно, где мои сообщения, где ответы Claude, где его действия; читать тяжело.

## 3. Что нужно

1. **Мои сообщения и ответы Claude визуально разделены**, как в мессенджере:
   - мои — справа или с явной плашкой/фоном своего цвета, подпись «Вы»;
   - Claude — слева, на своём фоне или с цветной полосой слева, подпись «Claude»;
   - отступ между репликами, время (часы:минуты) у каждой реплики, если оно есть в событиях.
2. **Действия Claude (инструменты) — отдельным видом**, не путаются ни с моими сообщениями, ни с текстом ответа:
   - компактная строка-«чип» под ответом: иконка по типу (команда, чтение файла, правка, поиск, веб, скриншот/буфер ПК, субагент), короткое человеческое название и цель (`Команда: pnpm test`, `Правка: src/voice.ts`);
   - состояние: идёт (…/спиннер) → готово (✓) → ошибка (✗, красным);
   - несколько действий подряд схлопываются в одну строку «5 действий» с раскрытием по клику (или показывать последние 3 + «ещё N»);
   - запросы разрешения (approve) — заметно, отдельным цветом: «Ждёт разрешения на телефоне».
3. **Читаемость:**
   - шрифт текста не меньше 10.5 pt, межстрочный интервал больше, поля по краям;
   - код — моноширинный блок на своём фоне, с языком сверху; длинные строки переносятся, а не уходят вбок;
   - ширина по умолчанию ~460 px (с учётом DPI), кнопка «высокое окно» остаётся;
   - стрим ответа без мигания и прыжков прокрутки (сейчас перерисовка хвоста — сохранить этот подход или лучше).
4. **Шапка:** название чата + статус Claude («думает…», «выполняет: …», «ждёт разрешения», «готово»), офлайн Мака — заметно.
5. Всё остальное сохранить: только чтение (окно ничего не отправляет), «Copy reply» / «Copy code» / двойной клик по коду копирует, темы, не крадёт фокус, нет в Alt+Tab, Esc/Alt прячет.

## 4. Ограничения

- Windows PowerShell 5.1 + WinForms (или WPF из PowerShell, если с ним проще сделать пузыри — но без внешних зависимостей, без .NET-установок, без скачиваний). Скрипт живёт строкой в `script.ts`: без обратных кавычек и `${` (см. комментарий в начале файла).
- Пузыри в одном `RichTextBox` сделать трудно — допустимо заменить на панель с отдельными контролами на реплику или на собственную отрисовку (`OnPaint`) с виртуализацией. Главное — не тормозить на чате в 300+ сообщений и не грузить CPU в простое (таймеры клавиш/ввода 25–30 мс уже есть — не добавлять новых постоянных).
- Модель (`model.ts`) можно расширять: передавать окну роль, время, тип инструмента, статус, группировку — логика группировки и подписи действий должна быть в TypeScript и покрыта тестами (`overlay-model.test.ts`), окно только рисует.
- Тексты интерфейса — по-русски.

## 5. Как работать

1. Ветка от `main`, каждое законченное изменение — commit и сразу push. PR в `main`.
2. `pnpm typecheck`, `pnpm test` зелёные.
3. Окно на Linux не запустить — проверь синтаксис PowerShell, если есть `pwsh` (`[System.Management.Automation.Language.Parser]::ParseInput`), и добавь тест, что скрипт парсится. В PR — скриншотов не будет, опиши словами, как выглядит, и что владельцу проверить на Windows.

## 6. Приёмка (владелец на Windows)

1. Двойной Alt → окно; сразу видно, где мои сообщения и где ответы Claude.
2. Claude запускает команды/правит файлы → действия видны отдельными строками со статусом, не мешают читать ответ; много действий подряд — схлопнуты.
3. Ответ с кодом → код читается, «Copy code» копирует.
4. Длинный стрим → без мигания, прокрутка не прыгает, если я читаю выше.
5. Тёмная и светлая темы обе читаемы.
